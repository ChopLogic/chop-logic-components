# useBodyScrollLock

The `useBodyScrollLock` hook prevents the page body from scrolling when active. This is useful for modal dialogs, full-screen menus, or any overlay that should capture user attention and prevent background scrolling.

## Features

- Prevents body scrolling by adding a CSS class (`cl-scroll-locked`) to the `html` element
- Preserves and restores scroll position when unlocked
- Automatically cleans up on component unmount
- Supports stacked dialogs — scroll is restored only when all locks are released

## Usage

```tsx
import React, { useState } from "react";
import { useBodyScrollLock } from "chop-logic-components";

const ExampleModal = () => {
  const [isOpen, setIsOpen] = useState(false);

  useBodyScrollLock({ isLocked: isOpen });

  return (
    <div>
      <button onClick={() => setIsOpen(true)}>Open Modal</button>
      {isOpen && (
        <div className="modal-overlay">
          <div className="modal-content">
            <h2>Modal Title</h2>
            <p>The page cannot be scrolled while this modal is open.</p>
            <button onClick={() => setIsOpen(false)}>Close</button>
          </div>
        </div>
      )}
    </div>
  );
};

export default ExampleModal;
```

## Preventing Layout Shift

When scroll is locked, the scrollbar disappears, which can cause a layout shift (content widens by the scrollbar width). To prevent this, add the following CSS rule to your global styles:

```css
html {
  scrollbar-gutter: stable;
}
```

The `scrollbar-gutter: stable` property reserves space for the scrollbar even when `overflow: hidden` is applied, keeping the content width constant.

**Browser support:** Chrome 94+, Firefox 97+, Safari 18.2+, Edge 94+ (~95% global coverage as of 2024).

For older browsers, the fallback is a minor layout shift when the scrollbar disappears, which is generally acceptable.

## Params

| Param        | Type      | Description                                                           |
| ------------ | --------- | --------------------------------------------------------------------- |
| **isLocked** | `boolean` | When `true`, prevents body scrolling. When `false`, allows scrolling. |

## Returns

`void`

## How It Works

The hook adds a `cl-scroll-locked` class to the `<html>` element when locked, which applies `overflow: hidden`. This class is defined in the library's `main.css`:

```css
.cl-scroll-locked {
  overflow: hidden;
}
```

When unlocked, the class is removed and the scroll position is restored.

## Best Practices

1. **Use with modals and overlays**: This hook is designed for components that overlay the page content and should prevent interaction with the background.

2. **Pair with focus trapping**: For accessible modals, combine this hook with `useModalFocusTrap` to ensure both scroll and focus are properly managed.

3. **Add `scrollbar-gutter: stable`**: To prevent layout shift when the scrollbar disappears, add this CSS rule to your global styles on the `html` element.

4. **Stacked dialogs work automatically**: Multiple components can use this hook simultaneously. Scroll will only be restored when all locks are released.

5. **Cleanup is automatic**: The hook automatically restores scroll position when the component unmounts, so you don't need to handle cleanup manually.
