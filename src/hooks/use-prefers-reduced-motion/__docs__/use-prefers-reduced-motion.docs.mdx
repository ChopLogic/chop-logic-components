# usePrefersReducedMotion

A React hook that detects whether the user has enabled the "reduce motion" accessibility setting in their operating system. This allows you to provide a more comfortable experience for users who are sensitive to motion.

## Features

- **Real-time Detection**: Automatically updates when the user toggles their system preference
- **SSR-Compatible Pattern**: Uses lazy initialization for the initial state
- **Automatic Cleanup**: Properly removes event listeners on unmount
- **Zero Dependencies**: Uses only native browser APIs

## Usage

```tsx
import { usePrefersReducedMotion } from "chop-logic-components";

const AnimatedComponent = () => {
  const prefersReducedMotion = usePrefersReducedMotion();

  return (
    <div
      style={{
        transition: prefersReducedMotion ? "none" : "transform 0.3s ease",
      }}
    >
      Content adapts to motion preferences
    </div>
  );
};
```

## Return Value

| Type      | Description                                              |
| --------- | -------------------------------------------------------- |
| `boolean` | `true` if reduced motion is preferred, `false` otherwise |

## Who Benefits From This?

- **People with vestibular disorders** — Animations can trigger vertigo, dizziness, and nausea
- **People with seizure disorders** — Flashing content can be a trigger for photosensitive epilepsy
- **People with ADHD or cognitive sensitivities** — Animations can be distracting
- **Anyone who prefers less motion** — Some users simply find animations unnecessary

## Best Practices

### Skip Decorative Animations

```tsx
const prefersReducedMotion = usePrefersReducedMotion();

// CSS approach
const style = {
  animation: prefersReducedMotion ? "none" : "bounce 1s infinite",
};

// Or skip entirely
if (!prefersReducedMotion) {
  triggerCelebrationAnimation();
}
```

### Provide Instant Feedback Instead of Delays

```tsx
const handleClick = () => {
  if (prefersReducedMotion) {
    // Execute immediately
    performAction();
    return;
  }

  // Show animation, then execute
  showFlashAnimation();
  setTimeout(performAction, 150);
};
```

### Keep Essential Motion, Remove Decorative Motion

Not all motion should be removed. Keep motion that conveys meaning:

- ✅ Keep: Progress indicators, loading states
- ✅ Keep: Scroll position indicators
- ❌ Remove: Parallax effects, bouncing elements
- ❌ Remove: Auto-playing carousels, decorative animations

## Testing

To test this hook, toggle the reduced motion setting on your system:

- **macOS**: System Settings → Accessibility → Display → Reduce motion
- **Windows**: Settings → Accessibility → Visual effects → Animation effects (off)
- **iOS**: Settings → Accessibility → Motion → Reduce Motion
- **Android**: Settings → Accessibility → Remove animations
